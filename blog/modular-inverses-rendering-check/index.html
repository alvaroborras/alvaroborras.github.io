Modular inverses: a rendering check

Álvaro Borrás · October 4, 2026 · example entry

This is an original test entry for checking mathematics and code rendering.

This entry checks inline equations, display equations, fractions, subscripts, and code blocks. It uses modular arithmetic as a small example.

A small inverse

A modular inverse of a modulo m is an integer x satisfying:

a⋅x≡1(modm)

For example, 3⋅4=12. Dividing 12 by 11 leaves remainder 1, so 4 is an inverse of 3 modulo 11.

3−1≡4(mod11)

When does it exist?

An inverse exists precisely when the number and modulus are coprime. Bézout's identity gives integers x,y such that:

a0x+m0y=gcd(a0,m0)

If the greatest common divisor is 1, reducing this identity modulo the modulus gives the inverse. Rearranging also gives a fraction with an integer value:

y=1−a0xm0

Runnable Python

Python 3.8 and newer support modular inversion directly with pow(a, -1, modulus). No custom algorithm is needed for this example. Copy the block into a Python file and run it:
